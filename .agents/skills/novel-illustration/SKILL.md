# 小説挿絵制作 (Novel Illustration)

**前提**: MCP・外部画像APIは使わない。Cursorエージェントの標準画像生成ツール（`GenerateImage`）のみ使用する。

## 対象プロジェクトの特定

1. ユーザーが指定した小説ディレクトリ（例: `小説/作品名/`）を使う。
2. 未指定なら、会話・開いているファイルから `小説/*/Images/挿絵制作ガイドライン.md` を探す。
3. 次を必ず読む（生成前）:
   - `{小説ルート}/Images/挿絵制作ガイドライン.md`
   - `{小説ルート}/Characters.md`

## ディレクトリ規約

| 用途 | パス |
|------|------|
| 背景参考 | `Images/Back/` |
| キャラ参考 | `Images/Characters/` |
| 生成物（上書き禁止） | `Images/Versions/{chapter_XX\|trial}/v_N.png` |
| 承認後の本番 | `第XX話.png`（ユーザーOK後のみコピー） |
| 制作ログ | `Images/Versions/{scene_id}/log.md`（キャラ／シーン毎。中央の `Images/log.md` は使わない） |

## ワークフロー

```
- [ ] 1. 必須ファイル読込・パス実在確認
- [ ] 2. 構成案提示（画風・サイズは未指定なら必ず確認）
- [ ] 3. ユーザー合意（画風・サイズ・解像度を含む）
- [ ] 4. プリフライト報告
- [ ] 5. 画像生成（1回のみ）
- [ ] 6. Versionsへコピー・当該 `Versions/{scene_id}/log.md` 更新
- [ ] 7. 結果報告（保存先・確認事項）
```

### 画風・サイズの確認（必須）

**未指定のままデフォルト値で生成してはならない。**

| 項目 | ユーザーが明示指定 | 未指定・曖昧 |
|------|-------------------|--------------|
| 画風 | その ID で構成案に記載 → 合意待ち | **推奨候補を提示し、必ず確認** |
| アスペクト | 同上 | **同上** |
| 解像度ヒント | 同上 | **同上**（省略希望も確認で確定） |

- 推奨候補の提示例は `visual-spec.md` の「確認用テンプレート」を使う。
- ユーザーが「既定でOK」「デフォルトで」「おまかせ」と**構成案を読んだうえで**返答した場合のみ、推奨値を確定値としてよい。
- **合意前に `GenerateImage` を実行しない。**

### 1. 構成案

生成前に箇条書きで提示し、**全体について**合意を得る:

- 背景ファイル、キャラ参考、座順・配置
- 表情・雰囲気・視線
- `Characters.md` から反映する身長・体格・髪・肌色・眼鏡の有無
- **画風**（ID + 日本語名）— 一覧は `visual-spec.md`
- **画像サイズ**（aspect ID + 比率の説明）
- **解像度ヒント**（`standard` / `high` / `4k-hint` / なし）

シーン指示だけ渡された場合でも、画風・サイズ・解像度の3項目は**省略せず**確認ブロックを出す。

### 2. プリフライト（対話内で明示）

- パス実在確認済み
- 参考画像 **3枚以内**（`reference_image_paths`）
- 最新の修正指示をプロンプトに反映済み
- **画風・サイズ・解像度はユーザー確認済み**（未確認のデフォルト適用なし）
- クォータ: 「本日○回目（残り○回）」を報告（日次上限12・同一シーン修正上限3）

### 3. 画像生成

- **1返信につき1回**の生成。ユーザーの明確な合意なく連続実行しない。
- 参考画像は絶対パスで `reference_image_paths` に渡す。
- プロンプトは英語推奨。`[OUTPUT]`（画風・サイズ）を先頭付近に置く。詳細は `prompt-template.md`、`visual-spec.md`。
- エラー時: 独断再試行せず原因報告。503はクォータ除外・**1時間冷却**。

### 4. 保存

1. ツール出力（通常 `assets/`）を取得。
2. `Images/Versions/{scene_id}/v_N.png` にコピー（`v_N` は既存の次番号）。
3. `Images/Versions/{scene_id}/log.md` に **画風ID・サイズID・実プロンプト全文**・参考画像パス・却下理由（あれば）を追記。記録失敗時は作業中断して報告。

### 5. 修正時

- 前回生成画像を参考に含めてもよい（3枚上限内）。
- 画風・サイズの変更が指示に含まれない場合: **「前回と同じ画風・サイズでよいか」**を必ず確認する（暗黙の継続としない）。
- 同一シーン2回目以降: 残り修正回数を明示。3回目以前に継続確認。

## 制作ルール（ガイドライン要約）

- **文字排除**: 画面内に文字・記号・ロゴ・透かしなし（プロンプトに `STRICT: No text...`）。
- **室内マナー**: 日本の住宅内は靴を履かない・コートを脱ぐ（カフェ等の公共空間は除外）。
- **視線**: 指示された対象と一致させる。
- **キャラ**: `Characters.md` が唯一の正。ガイドラインへ外見を転記しない。
- **上書き禁止**: 既存 `v_N.png` を上書きしない。

## 参考画像の使い方

| 枚数 | 典型例 |
|------|--------|
| 1 | 背景のみ、またはキャラ全身のみ |
| 2 | 背景 + キャラグループ参考（試作で成功） |
| 3 | 上記 + 前回生成物（修正時） |

配置・座順はプロンプトで明示（例: `Left to right: Chiaki, Natsuki, Haruto, Touka`）。身長階層も数値で記載。

## 応答言語

日本語。提案の押し付けは最小限。ユーザーの「OK」以外で本番ファイルへコピーしない。

## 推奨候補（確認用・自動適用しない）

ユーザー未指定時に**提案するだけ**で、確定は必ず確認後。

| 項目 | 推奨候補 | 提案する条件の例 |
|------|----------|------------------|
| 画風 | `anime` | キャラがアニメ立ち絵・背景がイラスト |
| 画風 | `photo-anime-hybrid` | 背景が実写写真 + キャラがアニメ |
| アスペクト | `16:9` | シーン挿絵・複数人・室内全景 |
| 解像度ヒント | `high` | 通常の挿絵（特に指定がなければ候補として提示） |

候補と異なる選択・「おまかせ」のいずれも、**返答をもって初めて確定**する。
