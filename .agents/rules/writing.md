# 小説執筆ルール

## 1. 表記・文字の厳格なフィルタリング（表記規制）
- **文字体系の制限**: ハングル・簡体字の使用を禁止し、日本語（必要に応じた一部英語）のみを使用すること。文字コードは必ず UTF-8 とすること。
- **特定記号の指定**: 半角ダッシュ「——」は使用禁止。必ず全角ダッシュ「――」を使用すること。
- **禁止ワードのハードブロック**: 「不器用」という単語は一切使用禁止。定型的なAI描写を避け、別の表現へ言い換えること。
- **数字のコンテキスト判別**:
  - 数量・時間・日付などの数値を扱うもの → 半角数字（例: 3年前、5名、2～3時間）
  - 熟語・成句・比喩など意味を持つことば → 全角漢数字（例: 二人きり、二度と、五人組、一旦）

## 2. レイアウト・レイヤーの構文ルール（フォーマット規約）
- **地の文の字下げ**: 地の文の段落先頭には、必ず全角スペースを1つ入れること。
- **セリフの独立化**: セリフ（会話文）の前後に空行を入れ、地の文と明確にブロック分離して可読性を高めること。
- **感嘆符・疑問符（！？）直後の半角スペース挿入**:
  - 会話文（セリフ）の途中で感嘆符（！）や疑問符（？）の後に文や言葉が続く場合、記号の直後に半角スペースを1つ挿入すること。
  - 「！？」のように記号が連続する場合は、記号の塊の直後に半角スペースを1文字入れること（記号の間にはスペースを入れない）。
  - ただし、セリフの末尾（閉じ鍵括弧「」」の直前）にはスペースを入れないこと。
  - **判定具体例**:
    - 〇（文の途中）: `「え？ なんで？」`、`「危ない！ 逃げて！」`、`「本当！？ それはすごい」`
    - 〇（文末・末尾）: `「本当なの！？」`、`「どうして？」`
    - ✕（誤り）: `「え？なんで？」`（スペース抜け）、`「え！？　なんで？」`（全角スペース誤用）、`「本当！？　」`（文末への余計なスペース）

## 3. 行数計算の物理計測（水増し・憶測の防止）
- **物理改行での計測**: 行数の目標が設定された場合、憶測や推測で申告せず、改行コード（\n）の実際の出現数で計測すること。
- **水増し改行の禁止**: 行数を稼ぐ目的で不自然に短い改行を入れるようなズルい方法を使用しないこと。

## 4. 対話・進行の制御（先走りの防止）
- **「次の提案」の遮断**: 執筆後の「次は〇〇を書きますか？」といった次の提案は一切不要。指示された内容の執筆のみに集中すること。
- **完了の自己判断禁止**: 執筆の完了はユーザー側で判断するため、AIが勝手に完了したと判断・宣言しないこと。
